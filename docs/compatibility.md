# 兼容清单

哪些应用能放进 MacBox、放进去之后是什么样。这份清单分两部分：**实测**（真的在盒子里启动过）和**静态检查**（只按 MacBox 添加应用时的同一套规则看了 App 包，没有运行）。

- 测试环境：MacBox 0.4.4 和 0.4.5，macOS 27.2，Apple Silicon。两个版本结果不一样的，表里写明了
- 测试日期：2026-11-11、12
- 应用版本会变，结论只对表里写的版本负责。你测到的不一样，或者测了表里没有的应用，欢迎[报告](https://github.com/PykeDLing/macbox/issues/new?template=compatibility.yml)（MacBox 里是「帮助 › 报告某个应用能不能用…」）

## 怎么测的

每个应用走同一套流程，用的是一份数据目录独立的 MacBox（不影响平时在用的盒子）：

1. **添加**：把官方安装包交给 MacBox，记下兼容性检查的结果
2. **打开**：在本机隔离里启动，等 25 秒，确认主进程还在、窗口画出来了（截图核对）
3. **退出**：请它退出，确认盒子里的进程都结束了
4. **运行报告**：看拦下了什么、启动了哪些程序、连了哪些服务器
5. **盒子外**：对比运行前后 `~/Library` 下各目录、`/Library` 下的启动项、主目录和 `/private/tmp` 的条目，看有没有东西落在盒子外

没有做的：**没有登录账号**，所以结论是“能启动到主界面或登录界面”，登录之后的功能（上传下载、播放、同步）没有覆盖；**虚拟 Mac 里只实测了微信**（见[虚拟 Mac 实测](#虚拟-mac-实测)），其余标成“需要虚拟 Mac”的只说明本机隔离装不下它。

## 图例

| 标记 | 意思 |
| --- | --- |
| ✅ 可用 | 本机隔离里正常启动，界面完整，退出干净 |
| ⚠️ 部分可用 | 能用，但有功能被拦下（开机自启、访达集成等），或者有东西留在盒子外 |
| 🖥 需要虚拟 Mac | 本机隔离装不下（自带苹果沙盒、要装驱动或系统服务），改用虚拟 Mac |
| ❌ 不可用 | 两种方式都不行，或者不是 Mac 应用 |

## 虚拟 Mac 实测

2026-11-12，MacBox 0.4.5。从设置虚拟 Mac 到在里面打开微信，全程在界面里操作，没有登录账号。

| 步骤 | 结果 |
| --- | --- |
| 设置虚拟 Mac | 用已经下载好的 macOS 27.2 镜像安装，约 3 分钟，占用约 25 GB（4 核、8 GB 内存）。第一次用要先下载约 25 GB 的镜像，时间看网速 |
| 第一次开机 | 自动建好账户并登录，直接到桌面，不用走设置向导。系统是英文、时区是美国太平洋时间，可以在虚拟 Mac 的系统设置里改 |
| 添加微信 | 把官方的 `WeChatMac.dmg` 交给 MacBox，提示“无法在本机隔离中运行”（自带苹果沙盒），点「改用虚拟 Mac」 |
| 打开 | MacBox 把安装包放进虚拟 Mac 的「传入」文件夹，打开虚拟 Mac 的窗口并开机。在虚拟 Mac 的访达里打开 My Shared Files › 传入，双击 dmg（第一次要等十几秒才挂载上），把微信拖进 Applications，再双击打开 |
| 睡眠、唤醒 | 睡眠后唤醒，微信停在原来的界面 |
| 关机 | 点 MacBox 的电源按钮，在虚拟 Mac 弹出的对话框里确认，正常关机 |

| 应用 | 版本 | 结果 | 说明 |
| --- | --- | --- | --- |
| 微信 | 4.2.0 | ✅ 可用（虚拟 Mac） | 装好后打开没有安全提示，约 10 秒到扫码登录页 |

要知道的：MacBox 只负责把安装包送进虚拟 Mac。安装、以及之后每次打开，都在虚拟 Mac 里自己操作（装好后从它的程序坞或 Applications 打开）；在 MacBox 里再点这个应用的「打开」，只会打开虚拟 Mac 的窗口。

## 为什么有的应用用不了

- **自带苹果沙盒的**（App Store 上的应用、微信、QQ 等）：套上 MacBox 的沙盒后一启动就会被系统结束，只能放进虚拟 Mac。
- **要往系统里装东西的**（驱动、系统扩展、管理员权限的常驻服务、输入法）：本机隔离不许写系统目录，放进虚拟 Mac。
- **主要功能放在 App 包里的后台服务（XPC）里的**（迅雷的下载）：这类服务由系统直接启动，不在沙盒里，MacBox 会结束它。0.4.5 起退出应用后会说明，并建议改用虚拟 Mac。

本机隔离挡什么、不挡什么，完整的说明在[工作原理和限制](how-it-works.md#限制)。
